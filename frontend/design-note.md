# 检索页

沿用纸色台面、墨线和朱红印。卡牌只从 TCGdex 英文国际版查询。

- 用户要做的事：用简体名前缀找到一只宝可梦，再看英文卡。
- 主动作：在搜索框里选定物种。
- 方向：桌上的检索纸。没出结果时搜索框是入口；出结果后卡图是桌上的实物，不再套一层卡片框。
- 关键状态：空页、候选、查找中、有结果、没有这张卡、详情、接口失败。
- 设备：宽屏多列卡，窄于 640px 时详情改成一列，卡图最宽 280px。
- 动效：按下缩到 0.98；候选从输入框上沿展开，收起更快；第一次进入时标题先于搜索框；卡图悬停抬起 2px。系统开启减少动态效果时直接到位。
- 验收：候选键盘和点击、分页、详情开关。

朱红印和标题同一行，表示卡面是英文，不是栏目眉标。标题用宋体写「宝可梦卡查」。页头说明删掉了，来源只留在页脚，链接用墨色，短页时沉到底部。朱红只出现在印上。

结果里不再重复卡名。有图的卡直接摆在纸上；没有图的卡改成文字条目，不再画空框。套装名留出两行高，同一行的编号对齐。
