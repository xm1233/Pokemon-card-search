# 宝可梦卡查

本机打开的搜索页。输入宝可梦的简体中文名，查看 TCGdex 英文国际版卡牌的图片和数据。页面上的说明文字是简体中文，卡名、套装名和招式效果来自英文数据。属性名会显示成火、水、草、电等简体说法。

TCGdex 的简体中文卡牌数据目前还不能用来查卡，所以这里先把简体物种名对上英文物种名，再查英文卡。

## 环境

需要 Python 3.10 或更新版本，以及能访问 TCGdex 的网络。查卡时会请求 `api.tcgdex.net`，卡图由浏览器直接加载 `assets.tcgdex.net`。

## 安装和启动

在项目目录执行：

```powershell
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器打开 http://127.0.0.1:8000 。

在搜索框输入简体名前缀，例如「皮卡」。从候选里点选或按回车确定一只宝可梦后，才会去查卡。结果每页 24 张，按套装 id 和编号排列。点开一张卡可以看大图、生命值、属性和招式。

## 搜索怎么对上卡

字典在 `data/species.json`，每条是全国图鉴默认物种的简体名和英文名，例如「皮卡丘」对应 `Pikachu`。

1. 中文按前缀匹配。至少输入 1 个字。「皮卡」能命中「皮卡丘」，「丘」不能。候选最多显示 30 条，写着「皮卡丘（Pikachu）」。
2. 确定物种之后，用英文名向 TCGdex 做包含查询，再在本地按整词留下卡牌。物种名前后必须是字符串边界，或者不是字母。因此 `Pikachu V`、`Pikachu-GX`、`Dark Charizard` 会留下，`Mew` 不会留下 `Mewtwo`。
3. 弯引号 `’` 和直引号 `'` 视为同一个字符。`Farfetch'd` 和 `Farfetch’d`、`Sirfetch'd` 和 `Sirfetch’d` 会一起查。

接口只接受字典里的英文名。训练家卡、物品卡、能量卡不能用这套物种名搜到。

## 更新字典

运行时不会访问 PokeAPI。全国图鉴增加新物种时，在项目目录执行：

```powershell
python scripts/build_species.py
```

脚本会下载 PokeAPI 的物种名表，写出新的 `data/species.json`。物种名里的弯引号会写成直引号。改完字典后重新启动服务，启动时才会读入新文件。

## 已知对不齐的名字

- 字典只有默认物种的简体名，没有区域形态别名。搜「六尾」会按 `Vulpix` 查卡，卡名里单独出现这个英文词的卡会留下，其中可以包括 `Alolan Vulpix`。直接输入「阿罗拉六尾」对不上任何物种。
- 除引号以外，如果 PokeAPI 的英文名和卡面印刷名不是同一个词，这只宝可梦会显示「这只宝可梦在英文国际版里没有卡」。
- 招式名称和效果保持英文。套装名也是英文。
